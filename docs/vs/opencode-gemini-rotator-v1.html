Architectural Differences

Dimension V1 Rotator (Legacy) V2 Rotator (This Plugin)
OpenCode Target OpenCode V1 (v1.x) OpenCode V2 (v2.2.0+)
Plugin Architecture Monkey-patches globalThis.fetch Native Plugin.define & ctx.session.hook
Async Runtime Standard JavaScript Promises Effect.ts Effect runtime hooks
Retry Logic Internal infinite retry while loop Integrated with OpenCode V2 retry budget (max 10 retries)
Domain Restriction Broad origin matching Strict HTTPS matching for generativelanguage.googleapis.com
UI Feedback TUI Sidebar / Toast popups Background debug logs (OPENCODE_GEMINI_DEBUG=1)

Migration Steps from V1 to V2

  1. Remove V1 Plugin: Delete old V1 plugin files from ~/.config/opencode/plugins/ and remove any V1 plugin references in opencode.json.
  2. Install V2 Rotator: Place index.ts into ~/.config/opencode/plugins/gemini-rotator/index.ts.
  3. Export Environment Variables: Maintain your existing GEMINI_API_KEYS variable list. Ensure GOOGLE_GENERATIVE_AI_API_KEY is set or connect Google via /connect in OpenCode V2.
  4. Restart Service: Run opencode service restart or start a fresh standalone session with opencode run --standalone.
