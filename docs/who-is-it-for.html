1. Developers Using OpenCode V2 CLI / TUI

If you use OpenCode 2.2.0+ as your primary AI terminal coding environment with Google Gemini models (e.g., google/gemini-2.5-flash or google/gemini-2.5-pro), this plugin eliminates annoying 429 Too Many Requests interruptions.

2. AI Coding Power Users with Free-Tier Gemini Keys

Google offers generous free RPM (Requests Per Minute) limits per project, but high-frequency coding agents easily exceed per-minute burst caps. Developers who maintain multiple API keys across separate Google Cloud projects can combine them into a single pool (1 to 256 keys).

3. Autonomous Background Coding Pipelines

When running automated code refactoring, test generation, or multi-step agent tasks using opencode run or opencode service, key rotation ensures background sessions do not fail abruptly due to temporary 503 backend spikes or quota throttles.

4. Developers Seeking Zero-Dependency Setup

No build tools, no npm install, no complex proxy servers to configure. Simply place index.ts in OpenCode's auto-discovery directory, export your keys, and start coding.
