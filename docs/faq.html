1. Why does Google Gemini return HTTP 429 in OpenCode?

Google Gemini enforces per-minute and daily rate limits (RPM/RPD) on free and pay-as-you-go tiers. Heavy automated coding requests in OpenCode easily trigger 429 Resource Exhausted errors when a single API key is throttled.

2. How do I rotate Gemini API keys in OpenCode V2?

Install opencode-v2-gemini-rotator by placing index.ts in ~/.config/opencode/plugins/gemini-rotator/ and set the GEMINI_API_KEYS environment variable containing a comma-separated list of keys.

3. Is OpenCode Gemini Rotator V2 free and open-source?

Yes, OpenCode Gemini Rotator V2 is 100% free and open-source software distributed under the MIT License.

4. How many Gemini API keys can I configure in the pool?

The plugin supports pools containing between 1 and 256 unique Google Gemini API keys.

5. Does key rotation bypass Google Cloud project rate limits?

No. Google applies rate limits per Google Cloud Project. To effectively increase your quota ceiling, configure keys generated across different GCP projects or Google accounts.

6. Does OpenCode Gemini Rotator V2 work with Vertex AI?

No. To prevent credential leaks, the rotator strictly targets official generativelanguage.googleapis.com endpoints and intentionally ignores Vertex AI and custom proxy origins.

7. How do I install the plugin without npm build step?

OpenCode V2 supports native single-file plugin auto-discovery. Simply place index.ts in ~/.config/opencode/plugins/gemini-rotator/. No npm install or build step is needed.

8. How does the plugin handle HTTP 503 Service Unavailable errors?

Upon detecting an HTTP 503 error, the plugin marks the key on a brief 10-second cooldown and rotates to the next available key in the pool.

9. What happens if an API key is invalid (API_KEY_INVALID)?

If a key returns API_KEY_INVALID or "API key not valid", it is permanently marked as invalid for the lifetime of the plugin process session.

10. How do I view live debug logs for key rotation in OpenCode?

Set OPENCODE_GEMINI_DEBUG=1 before starting OpenCode. Logs will be written to /tmp/gemini-rotator-debug.log without revealing sensitive key strings.

11. Is OpenCode Gemini Rotator V2 compatible with OpenCode 2.2.0?

Yes. It has been tested and verified on OpenCode 2.2.0 using multi-key production pools.

12. Does the plugin send my API keys to external proxy servers?

No. The plugin runs entirely locally within your OpenCode process space. Requests are sent directly to official Google endpoints.
