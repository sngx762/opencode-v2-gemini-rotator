1. Legacy OpenCode V1 Environments

This plugin is written strictly for the OpenCode V2 plugin model (introduced in OpenCode 2.0+). It relies on @opencode/plugin, Effect handlers, and session hooks. It will not work on OpenCode V1.

2. Google Vertex AI & Custom Proxy URLs

To prevent security risks and accidental credential leaking to third-party endpoints, the rotator exclusively matches https://generativelanguage.googleapis.com. Custom baseURL configurations and Vertex AI routes are deliberately ignored.

3. Multiple Keys from the EXACT Same Google Cloud Project

Google Cloud enforces Gemini API rate limits at the GCP Project level, not per individual key string. If you generate 5 API keys under the exact same GCP project, hitting a 429 rate limit on key #1 means keys #2–5 will also return 429. For true rate-limit expansion, generate keys across distinct Google Cloud projects or accounts.

4. Users Requiring Graphical TUI Status Bars

The original V1 rotator included custom TUI status bars and toast popups. In OpenCode V2, server plugins run asynchronously in background sessions without direct terminal UI rendering hooks. Progress can be monitored via debug logging (OPENCODE_GEMINI_DEBUG=1), but no TUI status bar is drawn.

5. Expecting Infinite Retry Loops

OpenCode V2 limits retry budgets (maximum 10 retries per main prompt turn). If all keys in your pool are exhausted or on long cooldowns, OpenCode will eventually terminate the request rather than hanging indefinitely.
